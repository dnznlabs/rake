A test page for the rake widget

This page is not part of the app and is served from a different site. It carries the embed snippet the app's own documentation prints for Ethereum and nothing else. The mount names a public endpoint, so it reads the distribution without a wallet, whatever wallet the visitor has and whatever chain that wallet is on.

The script is loaded from rake.dnzn.dev with an integrity attribute, so the browser refuses to run it if the bytes served differ from the bytes the app's build produced.

A test page for the rake widget

This page is not part of the app and runs on a host the app's authors do not control. It carries the embed snippet the app's own documentation prints for Base Sepolia, twice and nothing else: the first mount names a public endpoint, so it reads the distribution without a wallet; the second names none, so it reads through the visitor's wallet and shows its failure state when there is no wallet on Base Sepolia.

Base Sepolia rather than Sepolia because the hosted gateway answers 400 for this contract on Sepolia and 200 on Base Sepolia, so a page whose script came from the Sepolia host would load nothing and render nothing. The fault is that deployment's, not the contract's: the project's own build of the same gateway serves Sepolia correctly. The distribution is at the same address on both chains.
